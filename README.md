# Computer System Validation (CSV) Project

This repository contains a standard Computer System Validation (CSV) project structure with template documents to support GxP compliance.

Folders and primary documents:

- 01-Validation-Plan/Validation-Plan.md
- 02-URS/User-Requirements-Specification.md
- 03-Risk-Assessment/GxP-Risk-Assessment.md
- 04-Functional-Specification/Functional-Specification.md
- 05-Traceability/Traceability-Matrix.md
- 06-IQ/Installation-Qualification.md
- 07-OQ/Operational-Qualification.md
- 08-PQ/Performance-Qualification.md
- 09-Deviations/Deviation-Example.md
- 10-CAPA/CAPA-Example.md
- 11-Change-Control/Change-Control-Example.md

How to use:

1. Populate each template with system-specific information.
2. Record approvals and version history in each document header.
3. Link tests, evidence, and deviations into the Traceability Matrix.
